# Governance

## Current model

`voiage` is currently maintained by one maintainer. The maintainer sets the
roadmap, triages reports, manages releases, and makes final repository
decisions. Pull requests remain the auditable change boundary, and required
automated quality, security, documentation, and contract checks must pass
before merge. The protected branch does not require an unavailable independent
approval.

This is a description of the current operating model, not a claim of
multi-person community governance.

## Participation and decisions

Contributors may propose changes through GitHub issues, discussions, and pull
requests. Material API, numerical-policy, compatibility, security, and
governance changes should include their rationale, alternatives, migration
effects, and executable evidence where applicable. The maintainer records
larger decisions in repository specifications or Conductor tracks.

Conflicts of interest should be disclosed when they could affect a technical,
publication, or community decision. Everyone participating in the project must
follow `CODE_OF_CONDUCT.md`.

## Releases and publication

Repository preparation does not authorize a package upload, manuscript
submission, registry action, or acceptance claim. Release and publication
authority remains with the named maintainer or author, while registry,
editorial, archival, and review decisions remain external.

## Continuity

If additional sustained maintainers emerge, this document should be revised
through a public pull request to define delegated roles and decision rules.
If the current maintainer can no longer maintain the project, they may nominate
a successor with an established contribution record. If no successor is
available, the repository should be marked maintenance-only or archived rather
than presenting an unsupported maintenance commitment.

Security-sensitive maintainer changes must also update repository access,
release environments, trusted-publishing identities, security contacts, and
the applicable submission-readiness contracts.
