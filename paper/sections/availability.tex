\section*{Code and data availability}

The retained worked-example manifest identifies the historical v2.0.0
reproduction, with random seed 20260723 for the probabilistic analysis and
seed 20260724 for the bootstrap. Its portable outputs have been rechecked
with \texttt{voiage} version 2.2.0. The worked example
is generated by
\path{scripts/generate_paper_health_example.py}; all parameter draws and
figure data are synthetic and are recreated by that script. The plotted
study-value results and prespecified sensitivity scenarios are also provided
as machine-readable CSV files in \path{paper/data/}. Source code, release
artefacts, and checksums are available at
\url{https://github.com/edithatogo/voiage/releases/tag/v2.2.0}. The historical
v2.0.0 repository snapshot is archived by Software Heritage as
\url{swh:1:snp:31f89375852737bb9eb62ebc03fadfbc7ff70c2d}. A v2.2.0 Software
Heritage snapshot and DOI-bearing archive remain unconfirmed.
