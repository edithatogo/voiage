# Track Specification: Sustainability, Badging & Identifier Governance

## Scope & Purpose
Establish institutional, fiscal, and persistent identification governance for `voiage` across open-source scientific foundations and badge registries.

## Requirements
1. **Fiscal Sponsorship**: 501(c)(6) Open Source Collective documentation and transparent expense ledger.
2. **Security Badging**: Complete Passing-tier criteria evidence for OpenSSF Best Practices badge (Project ID 13835).
3. **Persistent Identifiers**: Canonical mapping of SciCrunch RRID, Software Heritage SWHID, and Zenodo release DOIs.
4. **Governance Evolution**: Documented pathway from solo-maintainer to multi-institution steering committee in `GOVERNANCE.md`.
