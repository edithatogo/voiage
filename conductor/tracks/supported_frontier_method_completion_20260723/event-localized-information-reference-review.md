# Event-localized information reference review

## Scope and sources

This review freezes the experimental C18/M27 contract for issue #596 and
delivery issues #777–#779. It was checked against two primary Decision Analysis
papers on 2026-08-01:

- Gordon Hazen, Emanuele Borgonovo and Xuefei Lu, “Information Density in
  Decision Analysis,” DOI `10.1287/deca.2022.0465`.
- N. Onur Bakır, “On the Value of the Tail Event Information,” DOI
  `10.1287/deca.2024.0172`.

## Frozen mapping

Hazen, Borgonovo and Lu define information density as a graphical complement
to expected-utility information value. The C18/M27 canonical density is
therefore policy-relative:

`i(x) = f(x) [max_a g_a(x) - g_a*(x)]`,

where `a*` is a baseline-optimal reference action and `g_a(x)` is the
conditional expected value or utility of action `a`. This density is
nonnegative and integrates to the value of resolving `X`. Complete baseline
ties are retained, but v1 requires the analyst to select one tied
baseline-optimal reference action so every atom is reproducible.

The centered expression

`j(x) = f(x) [max_a g_a(x) - V0]`

has the same integral because the reference-policy conditional value integrates
to `V0`. Its atoms can be negative. C18/M27 exposes it only as a signed
diagnostic and never substitutes it for the canonical policy-relative density.

Bakır's paper treats event information as the binary partition generated by an
event and its complement, then studies imperfect information through a binary
source whose reported label matches the event state with probability `p`.
C18/M27 evaluates that partition and channel by exact joint-probability
enumeration. Consequently, `p = 0.5` is uninformative and `p` has the same
gross decision value as `1-p` when the decision-maker can interpret the signal
labels. Both `p = 0` and `p = 1` reveal the event perfectly.

## Bounded adaptation

Bakır evaluates monetary buying price for a risk-averse decision-maker. Issue
#596 does not duplicate that root-finding method. It reports event EUI in the
declared objective unit and delegates BPI, wealth/reference state and payment
location to issue #595's expected-utility information-pricing contract.

The v1 evaluator uses finite probability masses rather than claiming a
Lebesgue density, continuous quadrature or density estimator. Equal coordinates
are grouped before conditional optimization, supporting univariate and
multivariate discrete references while preserving exact integral identities.
Ordinary threshold plots, DSA, parameter EVPPI, tail-risk measures and forecast
accuracy do not satisfy this estimand.

## Required assurance

- exact event/complement partition and positive probability on both cells;
- complete baseline, event, complement and signal-policy ties;
- policy-relative and centered integral residuals within declared tolerance;
- nonnegative canonical density atoms and explicitly signed centered atoms;
- `p`/`1-p`, `p=0.5`, perfect-channel, action/state permutation and grouping
  cases;
- strict deterministic schemas, fixtures, API/CLI and result-only plots;
- runtime input and result-semantic validation, a true-max reference policy,
  bounded tolerances, raw-atom integral assurance and explicit `null` for an
  unevaluated `p`/`1-p` symmetry check;
- experimental Python disposition, with Rust/R/Julia unsupported and Mojo an
  external upstream boundary;
- independent implementation/scientific review and hosted exact-head evidence
  before any maturity promotion.
