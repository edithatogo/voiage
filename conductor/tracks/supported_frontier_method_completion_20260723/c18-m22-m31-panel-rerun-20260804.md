This is a bounded, repository-owned panel rerun against the M22–M31 fixture,
contract, and test evidence on candidate `291347ba`. The panel is advisory

## Role reports

- M25: exact current/information × implementation decomposition with explicit interaction.

### Estimator assurance

Focused M22–M31 suites and the cross-family evidence audit pass (388 tests in
the rerun). The assurance reviewer records dissent: the audit currently proves
registration and executable test presence, not a complete reproducibility
corpus. Several pathology/property entries are descriptive strings or module
references; normative artifact existence, per-case hashes, and manifest-to-test
execution are not all independently checked. Property evidence is deterministic
parametrization, not randomized property-based sampling. These limitations
block any claim of complete independent estimator assurance.

### Cross-language and API

No Rust, R, Julia, or Mojo parity evidence was produced. The families remain
Python-only or explicitly unsupported in their capability records. Parity must
wait for one merged, exact Python semantics candidate and then use shared
fixtures with governed unsupported receipts for absent bindings.

### Governance and publication

All families remain experimental. Scientific approval, maintainer promotion,
hosted exact-head assurance, parity, release, publication, registry, and issue
closure remain separate open gates. The panel cannot replace accountable
decisions and cannot resolve dissent by majority vote.

## Disagreement and limitation register

The following are preserved rather than adjudicated away:

1. Complete evidence assurance is disputed: executable tests pass, but fixture
   corpus/hash linkage is incomplete.
2. M26 DVSS and general solver support are explicitly deferred.
3. M27 density evidence is discrete/diagnostic, not continuous estimation.
4. M28 is bounded to the declared finite horizon, branch budget, and policy class.
5. M29 welfare values require declared normalization when units are incomparable;
   no general equilibrium solver is claimed.
6. M30 distinguishes the contract-authoritative decomposition from the legacy
   static API to avoid naming ambiguity.
7. M31's tower identity is valid only under its declared classical assumptions.

## Panel disposition

`scientifically_acceptable_experimental` is recommended only for the bounded
repository semantics, with the above limitations attached. The stronger
alternative is `conditional_remediation_and_rereview` for complete fixture/hash
assurance. No stable, parity, release, publication, registry, or closure claim
is authorized by this rerun.
