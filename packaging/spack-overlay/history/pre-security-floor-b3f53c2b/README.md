These unchanged files record the pre-security-floor overlay at commit
`b3f53c2b1ad797a947e066dd9ea48540e4e19455`. The receipt's `log_path` and
`concrete_dag.path` fields resolve relative to this historical directory.

root. Recipe paths in the historical manifest identify files in that Git
commit, not the updated current overlay. This archive does not claim an
executable historical environment, native build or module-load result.
