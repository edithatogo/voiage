# AI usage disclosure

Generative AI tools have assisted with portions of repository development,
documentation, testing, review preparation, and editorial analysis.

AI-generated or AI-assisted output is not treated as authoritative evidence.
Retained changes must pass the same executable tests, numerical reference
checks, source review, licensing checks, and pull-request controls as other
changes. Automated accounts and AI agents do not count as human contributors,
independent users, reviewers, community engagement, authors, or approvers.

The human maintainer remains responsible for the software, scientific claims,
citations, releases, security decisions, and any external submission. An
external venue may require a more specific author affirmation or a list of
tools and model versions. Those details must be confirmed by the author from
authoritative records rather than inferred from repository content.

The JOSS-specific disclosure is retained in `paper.md`; its author-attestation
gate remains tracked separately because repository validation cannot supply a
human affirmation.
