`voiage` uses a small set of explicit data structures to keep method inputs and outputs serializable, inspectable, and stable across bindings.

## Core contract

The v3 contract uses **Polars wide frames** with ordered Float64 columns for the public tabular containers. Explicit strategy and parameter names preserve labels; Arrow/Parquet remains the cross-language interchange boundary.

## Key structures

- **`ValueArray`** — net benefit array with structured round-trip helpers (`from_polars()` / `to_polars()`)
- **`DecisionAnalysis`** — analysis orchestration facade
- **`Intervention`** — intervention definition
- **`DecisionProblem`** — decision problem formulation
- **`TrialDesign`** — trial design specification
- **`ParameterSet`** — parameter set with round-trip helpers (`from_polars()` / `to_polars()`)
