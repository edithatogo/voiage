This page describes the fixture-only `voiage` dataset registry, including
synthetic examples and non-executable open-data source mappings. The small
JSON files are repository-authored illustrative metadata fixtures; they are
not source-data snapshots and do not prove compatibility with a live source.

## Licensing

All data sources referenced in this registry carry their own licenses and
terms of use. Users must comply with the original terms for each dataset:

- **NHANES**: Public Domain (CDC/ATSDR)
- **MEPS**: Public Domain (AHRQ)
- **ClinicalTrials.gov**: Public Domain (U.S. National Library of Medicine)
- **World Bank**: CC BY-4.0
- **NOAA**: Public Domain (U.S. Government)
- **EPA**: Public Domain (U.S. Government)

## Citation

When using data from this registry in published work, cite both the original
data source listed in `specs/dataset-registry/registry.json` and the `voiage`
library.

## Transform status

The repository does not provide live refresh scripts. The transform directory
records the fail-closed promotion requirements for a future source-specific
implementation; network access is denied by default.

## Refresh policy

Illustrative fixtures in `specs/dataset-registry/snapshots/` are hash-bound in
the registry. A future refresh workflow must preserve raw-source receipts,
rights, deterministic transformation, and drift evidence before its output can
replace the fixture-only status.
