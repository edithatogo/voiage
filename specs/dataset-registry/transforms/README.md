# Dataset Registry Transform Status

There are no executable transforms in this directory. The registry is
fixture-only: its small JSON files are repository-authored illustrative
metadata, not downloaded source snapshots.

A future source-specific transform must be introduced through a reviewed,
network-denied-by-default workflow with source and rights receipts, raw-byte
SHA-256, deterministic normalized output, schema validation, drift reporting,
and explicit failure behavior. Until then, no live-refresh claim is allowed.
