# Approved Phase 3 roadmap proposal

The analyst approved the 15 review-bound capability gaps for roadmap planning
on 2026-07-27. This is a planning change only: it does not claim parity,
authorize implementation, or mutate GitHub issues.

The roadmap should retain the following work classes as separately gated:

- direct VOI/HTA method and estimator gaps (EVPI, EVPPI, EVSI and ENBS);
- model and decision-schema interoperability (CEA, Markov, decision-tree and
  distributional CEA inputs);
- reporting and analyst workflow lessons from public, documented surfaces;
- proprietary or hosted workflows retained as non-reproducible rather than
  compatibility targets.

Each later implementation must retain independent fixtures, explicit license
boundaries, and its own scientific/runtime approval.
